# VoiceChat — голосовой чат в браузере
Автор: **NightLord РВЕ**

Лёгкий чат с голосовыми сообщениями для своего VPS. Открывается в любом браузере
(ПК, Android, iPhone), без установки приложений.

- запись голосовых: нажал 🎤 → говоришь → ➤ отправить (или удерживай и отпусти, как рация);
- текстовые сообщения, кто в сети, удаление своих сообщений;
- новые сообщения приходят сразу, непрослушанные голосовые проигрываются подряд;
- вход по имени и общему паролю, защита от подбора пароля;
- **без зависимостей**: только Python 3 и openssl, которые уже есть на Ubuntu/Debian.

## Почему VPN не пострадает
- работает на **отдельном порту 8443** (443 остаётся за Xray/Reality);
- отдельная служба `voicechat` от отдельного пользователя, доступ на запись только в `/opt/voicechat/data`;
- 3x-ui, Xray, iptables и Docker не трогаются. Установщик лишь открывает порт в ufw/firewalld, если они включены;
- если порт занят — установщик остановится и ничего не сделает.

## Установка
Зайдите на сервер по SSH и выполните одну команду:
```
cd /root && curl -fsSL https://github.com/nightlords133-spec/VoiceChat/archive/refs/heads/main.tar.gz | tar xz && cd VoiceChat-main && bash install.sh
```
В конце будет показан адрес `https://IP:8443` и пароль. Другой порт: `VC_PORT=9443 bash install.sh`.

Браузер предупредит о сертификате (он самоподписанный) — «Дополнительно» → «Перейти на сайт».
Это нужно один раз; HTTPS обязателен, без него браузер не даст доступ к микрофону.

## Управление
| Действие | Команда |
|---|---|
| Статус / лог | `systemctl status voicechat` · `journalctl -u voicechat -f` |
| Сменить пароль | `nano /opt/voicechat/voicechat.env` → `systemctl restart voicechat` |
| Обновить | снова выполнить команду установки (пароль, история и голосовые сохранятся) |
| Удалить | `bash uninstall.sh` |

## Настоящий сертификат (без предупреждения)
Если у сервера есть домен и сертификат (например, выпущенный в 3x-ui), положите его вместо самоподписанного:
```
cp /root/cert/ДОМЕН/fullchain.pem /opt/voicechat/data/cert.pem
cp /root/cert/ДОМЕН/privkey.pem   /opt/voicechat/data/key.pem
chown voicechat: /opt/voicechat/data/*.pem && systemctl restart voicechat
```
и заходите по `https://ДОМЕН:8443`.

## Настройки (`/opt/voicechat/voicechat.env`)
`VC_PORT` — порт · `VC_PASSWORD` — пароль · `VC_HISTORY` — сколько сообщений хранить (по умолчанию 1000, старые голосовые удаляются автоматически).
